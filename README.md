### Satyawan Singh

ML engineer. I build open-source tools for LLM reliability.

**A set of four small, zero-dependency libraries for not trusting an unverified LLM output:**

| Library | Job | What it does |
|---|---|---|
| [**stigma**](https://github.com/ss1738/stigma) | aggregate | consensus over many models that learns which to trust |
| [**disco**](https://github.com/ss1738/disco) | search | verifier-grounded discovery, an open FunSearch |
| [**groundkit**](https://github.com/ss1738/groundkit) | ground | a model can propose a value, never assert a fact |
| [**certain**](https://github.com/ss1738/certain) | calibrate | conformal prediction sets and principled abstention |

All MIT, pure Python, with honest benchmarks in every README.
